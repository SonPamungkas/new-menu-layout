Experience a cleaner, more immersive main menu for Nuclear Option!

This mod overhauls the main menu layout to minimize clutter and give you a better view of the background (perfect if you use [custom background videos or images](https://github.com/Talon-One-Fighter-Squadron/Image-Replacer)). 

## Features
* **Transparent UI**: The left panel background is fully transparent for an unobstructed view.
* **Dynamic Hover Elements**: The "NUCLEAR OPTION" Logo, News Panel, and Hint Panel automatically slide off-screen to keep the menu clean. They will smoothly slide back into view when you move your cursor to their respective corners (Top Right, Bottom Left, Bottom Center).
* **Raised Button Layout**: The main menu buttons are shifted up to prevent bunching at the bottom of the screen.
* **Join LAN Button Support**: Fully compatible with the 'Join LAN Button' mod. If detected, it automatically un-anchors the LAN buttons and neatly organizes them into the main button container for a seamless look.
* **Performance Optimized**: Built with performance in mind. Zero overhead and no stuttering during scene loads.
